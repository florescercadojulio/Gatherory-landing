## Create your first event

When you open Gatherory for the first time:

1. Tap **Continue** on the welcome screen.
2. Tap **Create an Event**.
3. Enter the event name.
4. Review the proposed date and time, then adjust them as needed.
5. Add an optional location, budget cap, and cover image.
6. Tap **Create**.

Gatherory opens the new workspace so you can begin shaping the event immediately.

## Create another workspace later

If you already use Gatherory, open the **Workspaces** screen and tap the plus button labeled **Add workspace**. The same creation form appears.

Use a separate workspace when the gathering has a different main purpose, host group, guest group, or budget. Use related events inside the same workspace when the moments belong to one larger gathering.

## Choose the event name

Use a name everyone involved will recognize. “Alex & Jordan” may be clearer than “Wedding,” while “Lake Weekend” may be clearer than “Trip.” The name appears across the workspace and guest experience, so avoid internal shorthand that only one planner understands.

You can update the main event later if the name changes.

## Add the date, time, and location

The creation form lets you set:

- start date and time;
- optional end date and time;
- all-day status;
- time zone; and
- an optional location.

If a detail is not final, keep the rest of the plan moving without presenting a guess as confirmed. Gatherory supports related events that are still waiting for a date, which is useful for tastings, fittings, or planning meetings that are real but not scheduled yet.

## Set an optional budget cap

The main event can begin with the full budget. Later, you can allocate portions of that budget to connected events and keep expenses attached to the part of the gathering they support.

Leave the field empty if the budget is not ready. A blank amount is more useful than a number everyone mistakes for an approved limit.

## Add a cover

Choose a photo or create artwork that makes the workspace easy to recognize. The cover is visual context, not a required planning field. You can create the event without one and return later.

## Understand the five main views

After creation, Gatherory organizes the workspace into five areas:

1. **Home** shows the main event and the connected moments around it.
2. **Ideas** holds inspiration and possibilities before they are decided.
3. **Decide** helps the planning circle pass, consider, or love open ideas.
4. **Timeline** organizes scheduled and unscheduled events.
5. **Insights** shows budget and planning information across the gathering.

You do not need to fill every area immediately. Start with the next real decision.

## Add a related event

From the main event context, use the calendar-plus button on Home or the plus button in Timeline. Give the event a title or category, choose whether it is a planning moment or a guest experience, and add its date, location, people, description, attire guidance, budget, or costs as relevant.

Examples include:

- venue walkthrough;
- tasting;
- attire fitting;
- rehearsal;
- welcome dinner;
- ceremony;
- reception; or
- next-day gathering.

Each related event stays connected to the main event while keeping its own logistics clear.

## Invite collaborators

Open the event’s people controls or **Workspace Settings**, then choose **Manage People**. You can invite specific people or enable a collaborator invite link. Gatherory can require approval before someone joins and lets you choose the default planning permission.

Invite someone when you can explain what you want them to help with. That keeps the workspace useful and makes the collaborator’s first visit understandable.

## Add the first idea

Open **Ideas**, create an idea, and choose the event and category it supports. Add enough context for another planner to evaluate it: a title, note, estimated amount, image, or link as relevant.

When the idea is ready for a decision, review it in **Decide**. Approved event ideas can continue into **Timeline**, preserving the connection between the original thought and the scheduled plan.

## What to do next

Do not try to complete the entire event in one session. A strong first workspace only needs:

- a recognizable name;
- a realistic date or date range;
- the next connected event;
- one open idea; and
- the first person who genuinely needs to collaborate.

That is enough to give the gathering a center. The rest can grow around it.
