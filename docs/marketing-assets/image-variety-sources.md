# Birthday marketing image sources

Checked October 21, 2026. These temporary stock-photo images illustrate the birthday-dinner use case; they are not customers, testimonials, or depictions of the fictional Gatherory people. Each selected source page was marked free to use under the Unsplash License when checked. The iOS bundle uses 1100px-wide JPEG copies requested directly from the Unsplash CDN; site usage can use the responsive CDN URLs in the shared [manifest](./image-variety-manifest.json).

The main event, idea cards, and child events use eleven distinct Unsplash photo IDs. The pre-existing candlelit dinner photo is retained only for the decor idea. The flowers and cake cards use close-up compositions so their subjects remain legible above the native card text.
